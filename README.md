# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

Also includes my [tmux config and notification setup](tmux/README.md) (bell →
orange window flag → clickable macOS notification that jumps to the right
tmux window).
